Weaknesses & Improvement Plan

  • Subnetting still takes me a bit too long sometimes. Fix: I’m doing short timed practice so I get faster and more confident.
  • When something doesn’t work, I can waste time trying random fixes. Fix: I’m forcing myself to follow a checklist and change one thing at a time.
  • I sometimes say “it works” without testing enough. Fix: I now run a quick set of checks before I call it finished.
  • Permissions can be confusing (Windows + Linux). Fix: I practice small scenarios and write down what caused “access denied” so I remember it.
  • Automation dates/times can trip me up. Fix: I test different cases so I don’t get wrong times in calendar events.
  • When I’m in a rush, I can miss small requirements. Fix: I’m using quick checklists so I don’t skip details.
  • Time estimates aren’t always accurate. Fix: I break tasks into smaller chunks and track how long they really take.
  • Presentations can get too packed. Fix: I keep slides simple and focus on one idea per slide.
  • Explaining my work can be messy. Fix: I practice a short “problem → what I did → result” explanation before I present.
